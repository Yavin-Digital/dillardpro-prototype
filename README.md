# dillardpro-prototype

Scrollytelling prototype for Dillard Property Services. Baseline mirror of https://clientreview.co/dillardpro/ is tag `baseline-original`.

Site files live under `site/`. GitHub Pages publishes a snapshot of `site/` from the `gh-pages` branch (`dillardpro.clientreview.co`).

The page set is home, cheat sheet, availabilities, cities, reviews, and contact. `about.html` redirects to home. Copy pulled from https://www.dillardpropertyservices.com is indexed in `references/`.
